# Portfolio Website (Easy + Launch Ready)

This is a static personal portfolio website built with:
- HTML
- CSS
- JavaScript

## Why this stack?
- Very easy to learn and edit
- No server needed
- Fast loading
- Perfect for GitHub Pages hosting

## What is included?
- Multi-page website (not single page)
- `index.html` (Home + profile photo section)
- `documents.html`
- `trainings.html`
- `services.html`
- `education.html`
- `contact.html`
- Mobile responsive layout

## Quick edit guide
1. Open all HTML files and replace name, email, and social links.
2. Open `script.js` and edit:
   - `documentsData`
   - `trainingsData`
   - `servicesData`
   - `educationData`
   - `educationGalleryData`
3. In `index.html`, replace the 3 profile photo URLs in `.profile-wrap` with your own photos.
4. Replace image URLs in `script.js` with your own training/school/college photos.

## How to launch on GitHub Pages
1. Create a new GitHub repository (for example: `my-portfolio`).
2. Upload all files from this folder.
3. Go to repository `Settings` -> `Pages`.
4. In `Build and deployment`:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Click `Save`.
6. Wait a minute, then your live link will appear (example: `https://your-username.github.io/my-portfolio/`).
